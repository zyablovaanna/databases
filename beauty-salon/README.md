Проектирование базы данных салона красоты в ERwin data modeler

Предметная область – сеть салонов красоты. 
Каждый салон находится в
определённом городе, имеет адрес (улицу, дом), описание и график работы на
каждый день недели. В салоне имеются помещения (комнаты/кабинеты),
каждое из которых относится к определённому типу (например,
«маникюрная», «парикмахерская», «косметологическая») и характеризуется
номером и этажом.

В салоне работают мастера. Каждый мастер занимает определённую
должность. Для каждого мастера фиксируются фамилия, имя, отчество,
телефон и электронная почта. Мастер может оказывать несколько видов услуг,
при этом для каждой такой специализации устанавливается индивидуальная
стоимость.

Услуги классифицируются по типам (например, «Маникюр»,
«Стрижка», «Уход за лицом»). Каждая услуга имеет название и описание. Для
оказания некоторых услуг расходуются материалы (лаки, средства для ухода,
одноразовые инструменты и т.п.), их расход фиксируется.

Материалы поступают от поставщиков. Каждый материал хранится в
определённых единицах измерения (штуки, миллилитры, граммы) и имеет
текущий остаток на складе. Для поставки указываются дата, количество и цена
товара.

Клиенты салона – физические лица. О них хранятся фамилия, имя,
отчество, телефон, электронная почта и дата рождения. Клиент может
оформить скидочную карту определённого типа. Каждый тип скидочной карты
связан с типом услуги и содержит название, условия получения и процент
скидки. У одного клиента может быть несколько карт, выданных в разные
даты.

Запись на услугу содержит информацию о клиенте (и о его скидочной карте,
если он ею обладает), выбранной специализации мастера, кабинете, статусе
записи, типе оплаты, дате и времени. Общая стоимость записи рассчитывается
как цена услуги конкретного мастера минус скидка (если привязана карта)
